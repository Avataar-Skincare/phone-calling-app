# Development

## Prerequisites

| Tool        | Version                                       | Used for             |
| ----------- | --------------------------------------------- | -------------------- |
| Node.js     | 22 (see `.nvmrc`)                             | Everything           |
| EAS CLI     | ≥ 16 (`npm i -g eas-cli`)                     | Device builds        |
| JDK         | 17 (Android Studio's bundled JBR works)       | Local Android builds |
| Android SDK | via Android Studio                            | Local Android builds |
| Xcode       | **26 or newer** (Expo SDK 56 needs Swift 6.2) | Local iOS builds     |
| CocoaPods   | 1.16+, run with a UTF-8 locale                | Local iOS builds     |

The app needs a **development build**: it contains a native module, so Expo Go can't run the
calling features (it falls back to plain `tel:` links).

## First run

```bash
npm install
cp .env.example .env            # optional; defaults to Compass testing
eas build --profile development --platform android   # or ios; install the build on a phone
npm start                       # then open the app on the phone
```

To log in you need a phone number that exists as a user in the Compass environment you point at.

## Scripts

| Script                    | What it does                                                                                                    |
| ------------------------- | --------------------------------------------------------------------------------------------------------------- |
| `npm start`               | Metro dev server                                                                                                |
| `npm run android` / `ios` | Local native build and install (`expo run:*`)                                                                   |
| `npm run lint`            | ESLint (`eslint-config-expo` + Prettier compatibility)                                                          |
| `npm run format`          | Prettier, writes changes. `format:check` only checks                                                            |
| `npm run typegen`         | Generates expo-router route types (`.expo/types/router.d.ts`)                                                   |
| `npm run check:lockfile`  | Fails if `package-lock.json` lacks a required peer dependency (EAS Build runs `npm ci` and rejects such a lock) |
| `npm run typecheck`       | `typegen` then `tsc --noEmit`                                                                                   |
| `npm test`                | Unit and integration tests (Jest, `jest-expo`). `test:watch`, `test:coverage`                                   |
| `npm run test:contract`   | Read-only checks against Compass testing (needs `COMPASS_TEST_PHONE`, `COMPASS_TEST_OTP`)                       |
| `npm run bundle-check`    | Bundles Android and iOS JavaScript, then deletes the output                                                     |
| `npm run verify`          | All of the above checks. Run before opening a PR                                                                |

## Environments

| EAS profile   | Compass    | Distribution                      |
| ------------- | ---------- | --------------------------------- |
| `development` | Testing    | Dev client (APK / internal iOS)   |
| `preview`     | Testing    | Internal APK link, TestFlight     |
| `production`  | Production | Play internal testing, TestFlight |

Locally, `EXPO_PUBLIC_COMPASS_API_URL` in `.env` overrides the default (Compass testing). Screens
show a small "Testing" label whenever the app points at testing.

## Checking native code locally

`/android` and `/ios` are generated by `expo prebuild` and gitignored. Never edit them; change
`app.config.ts`, `app.json` or `modules/sim-dialer` instead.

```bash
npx expo prebuild --no-install

# Android (Kotlin)
cd android
JAVA_HOME="/Applications/Android Studio.app/Contents/jbr/Contents/Home" \
ANDROID_HOME="$HOME/Library/Android/sdk" \
./gradlew :sim-dialer:compileDebugKotlin

# iOS (Swift); needs Xcode 26+
cd ios && LANG=en_US.UTF-8 pod install
xcodebuild -project Pods/Pods.xcodeproj -target SimDialer -sdk iphonesimulator build
```

CI compiles the Android module on every pull request. iOS native code is compiled by EAS builds.

## Code conventions

- TypeScript strict with `noUncheckedIndexedAccess`. Imports use `@/` for `src/` and `@modules/`
  for `modules/`.
- Pure logic lives in `src/lib/` with a `*.test.ts` next to it. Test files start with
  `/// <reference types="node" />` so Node types stay out of app code.
- Phone numbers: `toIndianMobile` for login input, `toE164` for dialing, `maskPhone` in lists.
- Times shown to agents are IST (`src/lib/time.ts`); times sent to Compass are ISO UTC.
- New screens: run `npm run typegen` (or `npm start`) so route types include them.
